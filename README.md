# Creed Perfumes — متجر العطور الفاخرة (الجزائر 🇩🇿)

موقع تجارة إلكترونية متكامل وراقي لبيع العطور الملكية الفاخرة باسم **Creed Perfumes** مخصص حصرياً للسوق الجزائري بنظام **الدفع عند الاستلام (Cash On Delivery - COD)** وبدون أي بوابات دفع إلكتروني أو تسجيل دخول للزبائن.

التصميم مبني وفق هوية البوتيك الملكي الفاخر (**Luxury Haute Parfumerie — Noir & Bronze**):
- **اللون الأساسي**: أسود ملكي فاحم / فحمي داكن (`#151515` / `#242424`)
- **اللون الثانوي واللمسات**: برونزي عتيق وذهب شامبانيا ملكي (`#6E603F` / `#B89B5E`)
- **الخلفيات**: أبيض دافئ وعاجي فاخر (`#FAF8F5` / `#F7F4EE` / `#FFFFFF`)
- **الأزرار والتفاصيل**: خطوط راقية بحواف مدروسة وظلال فاخرة دقيقة (`luxury-gold`)
- **الخطوط**: Cairo و Plus Jakarta Sans
- **العملة**: الدينار الجزائري (`دج` / `DZD`) فقط
- **تغطية شاملة**: كافة الـ 58 ولاية جزائرية مع حساب تلقائي لرسوم الشحن ووقت التوصيل

## 🌟 المميزات الرئيسية

### 1. تجربة الزبون (Customer Experience)
- **طلب فوري وسريع (Guest Checkout)**: لا يحتاج الزبون لإنشاء حساب أو تذكر كلمة مرور، فقط يختار عطره ويطلب مباشرة.
- **دفع عند الاستلام 100% (COD)**: معاينة العطر والتأكد منه ثم دفع المبلغ نقداً للموزع عند باب المنزل.
- **قائمة الـ 58 ولاية جزائرية**: حساب تلقائي لسعر الشحن ومدة التوصيل لكل ولاية (من 400 دج للعاصمة حتى 1200 دج لأقصى الجنوب).
- **الهرم العطري المفصل (Fragrance Pyramid)**: استعراض نوتات القمة، القلب، والقاعدة لكل عطر.
- **سلة مشتريات ذكية تفاعلية**: إشعارات فورية وإمكانية تعديل الكميات وحفظ محلي دائم (`localStorage`).
- **زر الطلب المباشر**: شراء فوري ينقل الزبون لصفحة الدفع في خطوة واحدة.
- **صفحة تأكيد الطلب**: احتفال بالكونفيتي ورقم تتبع فريد (مثل `DZ-84921`) وتوجيهات واضحة للمكالمة الهاتفية.

### 2. لوحة تحكم الأدمن (Mobile-First Admin Dashboard)
- **مصممة خصيصاً للاستخدام من الهاتف**: شريط تنقل سفلي (Bottom Tab Bar) مريح للتحكم بيد واحدة.
- **حساب محمي واحد فقط**: تسجيل دخول بريد + كلمة مرور عبر المسار السري `/admin`.
- **إحصائيات فورية (KPIs)**: طلبات اليوم، الطلبات المعلقة، إجمالي الإيرادات بالدينار الجزائري، ومعدل التوصيل.
- **زر اتصال هاتفي مباشر (`tel:`)**: نقرة واحدة للاتصال بزبون الطلبية هاتفياً لتأكيد الشحن دون الحاجة لنقل الرقم يدوياً.
- **إدارة الطلبيات**: تصفية حسب الحالة (`pending`, `confirmed`, `shipped`, `delivered`, `cancelled`) وتصفية حسب الولاية.
- **إدارة العطور والمخزون**: إضافة عطر جديد، رفع الصور، تعديل الأسعار، ومراقبة نفاذ المخزون.
- **إدارة الفئات**: إضافة وتعديل وحذف تصنيفات العطور.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (Stitch Theme Tokens)
- **Database & Auth**: [Supabase](https://supabase.com/) (PostgreSQL + Auth + Storage)
- **Local Fallback**: نظام تخزين ذكي تفاعلي يعمل تلقائياً في حال عدم ضبط مفاتيح Supabase بعد لتجربة فورية
- **Icons**: Lucide React + Material Symbols Outlined
- **Deploy**: Vercel Ready

## 🚀 التشغيل المحلي (Getting Started)

1. **تثبيت الحزم**:
   ```bash
   npm install
   ```

2. **تشغيل سيرفر التطوير**:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`


## 🗄️ إعداد قاعدة بيانات Supabase (خطوة بخطوة)

1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. انسخ محتويات ملف `supabase_schema.sql` والصقها في **SQL Editor** داخل لوحة Supabase ثم اضغط **RUN**.
3. سينشئ السكريبت تلقائياً:
   - جدول `categories`
   - جدول `products` مع مصفوفة الصور والنوتات
   - جدول `orders` مع بنية JSONB
   - سلة التخزين `perfume-images`
   - سياسات الأمان RLS
   - البيانات الأولية لأشهر 8 عطور من دار Creed
4. في ملف `.env.local`، ضع مفاتيح مشروعك:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   ```
   يجب ضبط هذه المتغيرات في Netlify أيضاً. لا تضع مفتاح `service_role` في الواجهة أو في مستودع Git.
